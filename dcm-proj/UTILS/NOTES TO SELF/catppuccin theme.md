I apply the catppuccin theme locally by running the following commands in the terminal:

```zsh
THEME_NAME=catppuccin
curl -s -S https://raw.githubusercontent.com/saberzero1/quartz-themes/master/action.sh | bash -s -- $THEME_NAME
```

See [here](https://github.com/saberzero1/quartz-themes/tree/master/themes/catppuccin) for more info on the quartz catppuccin theme
